# Getting help

| You want to... | Go to |
|---|---|
| Ask "how do I...?" or "which blueprint fits?" | [GitHub Discussions > Q&A](https://github.com/OWNER/REPO/discussions) |
| Share something you built | Discussions > Show and tell |
| Report an outdated flag or broken blueprint step | Issue: **Blueprint drift or bug** |
| Report a CLI/engine bug | Issue: **Bug report** |
| Propose a new blueprint | Issue: **New blueprint proposal** |
| Report a security problem | Privately, see [SECURITY.md](SECURITY.md) |

Before asking, please run `doogle doctor` and include its output (it never prints secrets), plus
`doogle --version`. Redact project IDs and emails.

Doogle is maintained by volunteers. There is no paid support or SLA. For problems with Google
products themselves (billing, quotas, outages, account access), use Google Cloud or Firebase
support; Doogle is not affiliated with or endorsed by Google LLC and cannot help with your account.
